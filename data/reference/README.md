# Reference data

Reference tables in this directory are public-source inputs or transparent
demonstration policy data. Each table must identify its source, version, units,
conversion, and limitations in the corresponding documentation.

`dleb-2026q1.csv` contains the Demonstration Living Expense Benchmark described
in [`docs/living-expense-benchmark.md`](../../docs/living-expense-benchmark.md).
It is not HEM data and must not be labelled as HEM.
